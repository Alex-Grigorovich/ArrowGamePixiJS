# ArrowPixi — Дизайн-документ

> Казуальная головоломка про стрелки. Платформа публикации — **Яндекс Игры**.
> Стек: **PixiJS 8.8 + TypeScript 5.7 + Vite 6**.

---

## 1. Краткое описание

**ArrowPixi** — головоломка-«чистилка» на сетке 4×4. На активной фигуре поля расставлены стрелки разного цвета и направления. Игрок тапает по стрелке — она скользит в свою сторону: если путь до края свободен, стрелка улетает за поле и исчезает; если впереди другая стрелка, она доезжает вплотную к ней и остаётся на поле. Цель уровня — полностью очистить поле как можно быстрее. Чем быстрее очищено поле, тем выше рейтинг звёзд. С ростом уровня фигуры усложняются, скорость растёт, добавляются стрелки-препятствия.

- **Жанр:** казуальная головоломка / тайм-киллер.
- **Сессия:** 1–3 минуты на уровень, «ещё один уровень».
- **Аудитория:** широкая, мобайл + десктоп.
- **Управление:** один тап / клик.

---

## 2. Игровой цикл (Core Loop)

```
Старт / загрузка сейва → уровень из SaveData (старт таймера)
   → [туториал на 1 уровне, пока игрок не тапнет]
   → анализ поля → тап по стрелке → стрелка скользит / улетает за край
   → [пауза: оверлей, стоп таймера, блок ввода; повторный клик — продолжить]
   → поле очищено?  ── да → стоп таймера → экран победы (звёзды)
                     │           → runScore → wallet (× coinBoost)
                     │           → [interstitial, если SDK доступен]
                     │           → следующий уровень → сразу новый уровень
                     └─ нет → продолжить тапать
```

Подкрепление: очки за стрелку, монеты в кошелёк после победы, частицы, цветные «следы», звёзды с анимацией, магазин апгрейдов.

---

## 3. Правила и механики

### Поле
- Базовая сетка **4×4**, но активна только одна из **27 фигур** (квадраты, линии, «Г», «Т», «П», пирамиды, трапеции, ступени, спираль, гексагон, полное поле и т.д.) — см. таблицу `SHAPES` в `GameApp.ts`, разбитую на 6 уровней сложности фигуры.
- Каждая клетка фигуры содержит стрелку: **направление** (↑ ↓ ← →) + **цвет**.
- Палитра цветов: **standard** (красный), **orange**, **blue**, **green**. Цвета распределяются равномерно и перемешиваются (`GridManager.buildColorPool`). Синие стрелки чуть шире (×1.2).

### Действие игрока (скольжение)
Тап по стрелке сканирует клетки в её направлении:
- **Путь свободен до края** → стрелка улетает за поле, исчезает с анимацией и частицами, оставляет цветной «след», начисляется **+1 очко**.
- **Впереди (вплотную) препятствие** → ход невозможен, стрелка дрожит (без штрафа).
- **Есть свободные клетки, но затем препятствие** → стрелка съезжает до последней свободной клетки перед препятствием и остаётся на поле.

Препятствием считается любая другая стоящая (не летящая и не удаляемая) стрелка.

### Счёт и монеты
- **`runScore`** — очки за текущую сессию. Отображаются в HUD (`ScoreUI` + `UiMoney.png`), растут за каждую улетевшую стрелку. Накапливаются сквозь уровни, сброс не реализован.
- **`wallet`** — постоянный кошелёк (`UpgradeManager`). **На HUD не показывается.** После победы: `wallet += round(runScore × coinMultiplier)`, где `coinMultiplier` зависит от `coinBoost`.
- Покупки в магазине списывают монеты из `wallet`. В шапке магазина отображается **«Монеты: N»** с автообновлением после покупки.

### Пауза
- Кнопка **`Pause.png`** на HUD под `Cart`, надпись **«Пауза»** по центру (`PauseButtonUI`).
- **Первый клик:** тёмный оверлей + `PauseCenter.png` по центру (`PauseScreen`), `TimerUI.pause()`, блокировка кликов по стрелкам и бонусам (`GameApp.setPaused`).
- **Повторный клик** по той же кнопке — снятие паузы (`unpause()`).
- Пауза **автоматически снимается** при победе и при «Заново» в настройках.
- На **1 уровне** во время стартового туториала кнопка паузы заблокирована (как Settings/Cart).

### Победа
- **Победа:** на поле не осталось стрелок → таймер останавливается → экран Win со звёздами → следующий уровень стартует сразу.
- **Поражения нет.** Игрок может перезапустить текущий уровень из настроек («Заново»).

### Рейтинг (звёзды по времени)
Звёзды (1–3) начисляются по времени прохождения уровня. Пороги заданы таблицей `STAR_THRESHOLDS_BY_LEVEL`:

| Диапазон уровней | 3 звезды (≤ сек) | 2 звезды (≤ сек) | иначе |
|------------------|------------------|------------------|-------|
| 1–2   | 12 | 22 | 1 ★ |
| 3–4   | 15 | 26 | 1 ★ |
| 5–6   | 18 | 30 | 1 ★ |
| 7–9   | 22 | 35 | 1 ★ |
| 10–12 | 26 | 41 | 1 ★ |
| 13–16 | 30 | 48 | 1 ★ |
| 17+   | 36 | 56 | 1 ★ |

## 4. Бонусы (Power-ups)

| Бонус | Действие | Запас |
|-------|----------|-------|
| **Change** | Развернуть выбранную стрелку в противоположную сторону | 3 / 2 / 1 |
| **Bomb** | Уничтожить выбранную стрелку и одну соседнюю + эффект частиц | 3 / 2 / 1 |

Активация: тап по кнопке → режим выбора → тап по стрелке. Режим автоматически сбрасывается через 5 секунд.

При **0 зарядов** кнопки остаются кликабельными: тап открывает **оффер rewarded-рекламы** (`RewardedOfferScreen`). По `onRewarded` — +1 заряд выбранного бонуса и `persist()`. Если реклама недоступна — переход в магазин. Магазин также доступен через `Cart` или кнопку «Магазин» в оффере.

Базовый запас (`getBasePowerUpUses`): уровни 1–3 → **3**, 4–8 → **2**, 9+ → **1**.

К старту уровня прибавляются уровни апгрейдов: `extraChange` → Change, `extraBomb` → Bomb (`GameApp.restartCurrentLevelState`).

## 5. Апгрейды (магазин улучшений)

> Постоянные улучшения, которые игрок покупает за монеты и которые сохраняются между сессиями. Это мета-прогрессия поверх уровней: даёт цель копить очки и причину возвращаться.

### 5.1. Базовые сущности (реализовано для MVP)

- **`runScore`** — очки в HUD (`ScoreUI`), растут за каждую улетевшую стрелку.
- **`wallet`** — постоянный кошелёк (`UpgradeManager`). На HUD не показывается. Зачисление после победы, списание при покупке.
- **Доход:** `wallet += round(runScore × getCoinMultiplier())` в `onWin` (`main.ts`). Множитель: `1 + coinBoostLevel × 0.2`.
- **Состояние апгрейдов:** `Record<UpgradeId, number>` в `SaveData`. Сохранение: `localStorage` + Yandex `player.setData` (см. §10).

### 5.2. Список апгрейдов (рекомендованный набор)

Все апгрейды многоуровневые. Цена растёт геометрически: `cost(level) = baseCost * growth^level`.

| ID | Название | Эффект на уровень | Max | base / growth | Куда подключается |
|----|----------|-------------------|-----|---------------|-------------------|
| `extraChange` | Заряды «Разворот» | +1 стартовый заряд Change | 3 | 100 / 1.8 | `getPowerUpUses` → `changeButton.reset()` |
| `extraBomb` | Заряды «Бомба» | +1 стартовый заряд Bomb | 3 | 120 / 1.8 | `getPowerUpUses` → `bombButton.reset()` |
| `coinBoost` | Жадность | +20% монет за уровень | 5 | 150 / 1.6 | множитель в начислении `wallet` |
| `bombRadius` | Мощная бомба | бомба бьёт всех 4 соседей (а не 1) | 1 | 400 / — | `useBomb()` — фильтр соседей |
| `timeGrace` | Хронометр | +2 сек к порогам 2★/3★ | 3 | 200 / 1.7 | сдвиг в `getStarThresholdsForLevel` |
| `pathPreview` | Предпросмотр | подсветка пути/клетки, куда уедет стрелка | 1 | 300 / — | hover в `Arrow` / `handleArrowClick` (только скан) |
| `slowMo` | Заморозка | старт уровня: таймер стоит первые N×1.5 сек | 3 | 250 / 1.7 | задержка `timerUI.start()` |

Минимально жизнеспособный набор для первой итерации: **`extraChange`, `extraBomb`, `coinBoost`**. Остальные — по мере полировки.

### 5.3. Архитектура (реализовано)

Модуль **`src/game/Upgrades.ts`**:

```ts
export interface SaveData {
  currentLevel: number;
  bestStarsByLevel: Record<string, number>;
  settings: { soundEnabled: boolean };
  wallet: number;
  upgrades: Record<UpgradeId, number>;
  shopTutorialSeen: boolean;
}
```

`UpgradeManager` — единая точка правды для MVP-апгрейдов:

- `getLevel` / `getCost` / `canBuy` / `buy` / `getWallet` / `addCoins`
- `getBonusBonus()` → `{ change, bomb }` для зарядов бонусов
- `getCoinMultiplier()` → множитель дохода
- `loadSaveData()` / `saveSaveData()` — `localStorage`, ключ `arrowpixi_save`, с нормализацией (`normalizeSaveData`)
- `persist()` в `main.ts` — пишет в localStorage и в Yandex (`yandex.saveSave`)

Модуль **`src/platform/YandexGames.ts`** (`YandexGamesService`):

- `init()` — загрузка SDK, `YaGames.init()`, `getPlayer()`
- `loadSave()` / `saveSave()` — облачный сейв; при первом запуске миграция из `localStorage`
- `markLoadingReady()` — `LoadingAPI.ready()`
- `showInterstitial()` — fullscreen между уровнями (кулдаун 60 сек)
- `showRewarded(onRewarded)` — обёртка `showRewardedVideo()` готова, в геймплей пока не подключена

**Не реализованы** (запланированы в §5.2): `getBombHitsAllNeighbors`, `getStarTimeGraceSec`, `getStartFreezeSec`.

### 5.5. UI магазина (реализовано)

Экран **`src/ui/UpgradeScreen.ts`**: dim-фон, окно `SettingsWindow.png`, заголовок **«Магазин»**, кнопка **Close** в правом верхнем углу. Анимация появления — как в `SettingsScreen` (scale 0 → target за 400 ms).

**Шапка:** заголовок «Магазин» + строка **«Монеты: N»** (`upgradeManager.getWallet()`), обновляется при каждой покупке.

**Вход в магазин:**

| Способ | Статус |
|--------|--------|
| Кнопка **`Cart.png`** на HUD под шестерёнкой | есть |
| Клик по **Change** / **Bomb** при 0 зарядов | есть |
| Пункт на экране победы | нет |

**Вёрстка окна (3 столбца × 3 строки):**

| Столбец | Содержимое |
|---------|------------|
| 1 — цены | Число монет (`#FFE55F`, крупный шрифт). После покупки пересчитывается по `baseCost * growth^level`. |
| 2 — кнопки | `CartBomb.png`, `CartChange.png`, `CartCoin.png` + подпись «Купить» / «Максимум». |
| 3 — описание | Текст из `formatShopCardText()` (`upgradeTexts.ts`), **18pt**, цвет `#FFE55F`. |

Порядок строк: **Bomb → Change → Coin** (`extraBomb`, `extraChange`, `coinBoost`).

Тексты карточек — `src/game/upgradeTexts.ts` (`MVP_UPGRADE_TEXTS`, `formatShopCardText`).

#### Тексты карточек (MVP, компактный вид в UI)

| ID | Название | Описание в магазине | Строка эффекта |
|----|----------|---------------------|----------------|
| `extraBomb` | Заряды «Бомба» | Больше бомб на старте уровня. Убирай лишние стрелки… | `+1 заряд «Бомба» (макс. +3)` |
| `extraChange` | Заряды «Разворот» | Дополнительные заряды бонуса «Разворот»… | `+1 заряд «Разворот» (макс. +3)` |
| `coinBoost` | Жадность | После победы в кошелёк попадает больше монет… | `×1.2 к доходу` (динамически по уровню) |

Подписи кнопок: **«Купить»**, **«Максимум»**. При нехватке монет кнопка полупрозрачная и неактивна (без текста-подсказки).

**Туториал магазина:** оверлей при первом открытии; флаг `shopTutorialSeen` сохраняется в `SaveData`.

**HUD:** один индикатор с иконкой монет — только `runScore`. Баланс `wallet` на экране не дублируется (осознанное решение: не два счётчика).

**Цены** (`cost = round(baseCost × growth^level)`):

| ID | base | growth |
|----|------|--------|
| `extraChange` | 100 | 1.8 |
| `extraBomb` | 120 | 1.8 |
| `coinBoost` | 150 | 1.6 |

### 5.6. Баланс и сохранение

- Цены подобрать так, чтобы первый апгрейд был доступен через 2–3 уровня игры.
- Двойной сейв: `localStorage` (`arrowpixi_save`) + Yandex `player.setData` (тот же `SaveData`).
- Поля: `currentLevel`, `bestStarsByLevel`, `settings.soundEnabled`, `wallet`, `upgrades`, `shopTutorialSeen`.
- При загрузке: облако приоритетнее; если облака нет — берётся localStorage и пушится в Yandex.
- Нормализация: `level <= maxLevel`, `wallet >= 0`.

**Ассеты магазина:** `Cart.png`, `CartBomb.png`, `CartChange.png`, `CartCoin.png`, `SettingsWindow.png`, `Close.png`.

## 6. Прогрессия сложности

| Параметр | Уровень 1 | Рост | Потолок |
|----------|-----------|------|---------|
| Сложность фигуры | простые формы (diff 1–2) | окно сложности растёт по уровню | полное поле 16 клеток (diff 6) |
| Скорость полёта | 450 мс | −15 мс/уровень | 200 мс |
| Пары-препятствия | 0 | +1 примерно каждые 3 уровня (+ шанс 35%) | 7 пар |
| Запас бонусов | 3 | ур. 4–8: 2 | ур. 9+: 1 |

Окно сложности фигуры (`getShapeDifficultyRange`): ур. 1–2 → 1–2, 3–4 → 1–3, 5–6 → 2–3, 7–9 → 2–4, 10–12 → 3–5, 13–16 → 4–6, 17+ → 5–6. Одна и та же фигура не выпадает два раза подряд.

Препятствия ставятся только между соседними стрелками **разного цвета**. На уровне 1 препятствий нет.

## 7. Туториал

### 7.1. Стартовый туториал (уровень 1)

`TutorialOverlay` + **`Arrow2.png`**.

| Условие | Поведение |
|---------|-----------|
| Когда показывается | Только **уровень 1**, пока игрок не тапнул по стрелке в текущей сессии |
| Повтор при перезагрузке | **Да** — состояние не сохраняется, после F5 туториал снова на 1 уровне |
| После первого тапа | Скрывается до конца сессии |
| Указатель | `Arrow2` привязан к экранным координатам игровой стрелки |
| Таймер | Запускается со стартом уровня, но **останавливается** на время туториала; после клика по стрелке — продолжается |
| Блокировка HUD | Пока туториал активен — **нельзя** открыть **Настройки**, **Магазин** и **Паузу** (`Settings` / `Cart` / `Pause` отключены, `alpha` 0.65) |
| Блокировка поля | Нет — игрок может сразу тапнуть по стрелке |

Текст: «Нажми на стрелку. Она скользит до препятствия или улетает за край.»

### 7.2. Туториал магазина (первое открытие)

| Условие | Поведение |
|---------|-----------|
| Когда показывается | При **первом** открытии `UpgradeScreen` (флаг в сейве) |
| Повтор при перезагрузке | **Нет** — `shopTutorialSeen` в `SaveData` |
| Закрытие | Тап по оверлею |
| Содержание | Оверлей поверх окна: три столбца (цена / кнопка / описание), перенос строк; «Нажми, чтобы продолжить» |

### 7.3. Туториал бонусов (уровень 2)

`TutorialOverlay.showStep()` + указатель `Arrow2`.

| Условие | Поведение |
|---------|-----------|
| Когда показывается | **Уровень 2**, один раз за сессию (если сейв ≤ 2 уровня) |
| Повтор при перезагрузке | **Да** — состояние не сохраняется; при F5 на 2 уровне туториал снова |
| Пропуск | Если в сейве уровень **> 2** — туториал не показывается |
| Блокировка HUD | Пока активен — **нельзя** открыть Settings / Cart / Pause |
| Таймер | Остановлен на всё время туториала бонусов; продолжается после завершения последнего шага |
| Шаги | 1) «Разворот» → кнопка Change → выбор стрелки на поле; 2) «Бомба» → кнопка Bomb → выбор стрелки на поле |

Тексты шагов:
- Change: «Нажми «Разворот», затем выбери стрелку на поле.»
- Change (поле): «Выбери стрелку — она развернётся в другую сторону.»
- Bomb: «Нажми «Бомбу», затем выбери стрелку на поле.»
- Bomb (поле): «Выбери стрелку — она и сосед исчезнут с поля.»

### 7.4. Не сделано

- Сохранение флага стартового туториала (уровень 1) — только в сессии; `shopTutorialSeen` — в сейве (local + Yandex).
- Сохранение флага туториала бонусов (уровень 2) — только в сессии.

## 13. Технические заметки

```
src/
  main.ts              — точка входа, HUD, сейв, Yandex SDK, туториалы, магазин, пауза
  assets/loadAssets.ts — загрузка текстур (без заглушек)
  platform/
    YandexGames.ts     — SDK init, облачный сейв, interstitial/rewarded
  game/
    GameApp.ts         — уровни, клики, бонусы, звёзды, туториал-таргет, апгрейд-заряды, setPaused
    Upgrades.ts        — UpgradeManager, SaveData, normalizeSaveData, localStorage

    Arrow.ts           — спрайт, полёт/скольжение
    ParticleSystem.ts
    WinScreen.ts
    upgradeTexts.ts    — тексты карточек магазина (MVP)
  ui/
    ScoreUI, TimerUI (pause/resume), LevelUI
    ChangeButtonUI, BombUI
    SettingsScreen, UpgradeScreen, TutorialOverlay
    PauseScreen, PauseButtonUI, RewardedOfferScreen
  types/types.ts
```

### Ассеты (`/public/assets/`)
Все игровые PNG лежат в репозитории. Список обязательных файлов задан в `REQUIRED_ASSET_URLS` (`loadAssets.ts`). При отсутствии любого файла игра не запустится — заглушки отключены.

Ключевые файлы: `background.png`, `Arrow2.png`, набор `Arrow*.png` (4 цвета × 4 направления × normal/bold), `Win.png`, `Star.png`, `Close.png`, `Bomb.png`, `Change.png`, `Settings.png`, `Cart.png`, `CartBomb.png`, `CartChange.png`, `CartCoin.png`, `SettingsWindow.png`, `UiMoney.png`, `SoundNo.png`, `soundCheck.png`, `Pause.png`, `PauseCenter.png`.

### Загрузка сейва при старте (`main.ts`)
1. `loadSaveData()` из `localStorage`
2. `yandex.loadSave()` из облака
3. `saveData = remote ?? local`; если облака нет — пуш local в Yandex

### Запуск
```bash
npm install
npm run dev      # разработка
npm run build    # lint + tsc + vite build → dist/
```

Сборка `dist/` упаковывается в zip для консоли Яндекс Игр.
